# C++ Concurrency in Action — Code Listings

This folder contains code listings and examples based on the book **[C++ Concurrency in Action](https://www.manning.com/books/c-plus-plus-concurrency-in-action)** by Anthony Williams.

## Purpose

The code in this folder is written as a learning exercise to deepen my understanding of the concurrency concepts discussed in the book.

Wherever possible, I also write small tests or experiments around the examples to explore how the code behaves and to better understand the underlying concepts.
